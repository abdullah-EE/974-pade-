# 974 Padel Design System

974 Padel is a premium Qatar-focused padel court discovery, open-game, challenge, and verified ranking app.

## Product loop
Find court -> view availability-style slots -> book externally -> create/open ranked match -> play -> submit result -> verify -> rank changes -> challenge/rematch.

## Visual identity
Use Qatar/Gulf premium sports-club identity:
- Primary maroon: #660033
- Deep maroon: #3A001D
- Accent maroon: #8A1E4D
- Pearl background: #F7F3F0
- Card white: #FFFFFF
- Text primary: #171014
- Text secondary: #6F666B
- Border: #E8DFE3
- Dark premium section: #1A1015

Avoid gold, random blue, purple gradients, full-black dashboard UI, generic SaaS cards, triangle icons, fake filler text, wrong sport images, and cramped stat blocks.

## Home priority
The app opens on Play/Courts. Play is the hero screen and must feel useful within 10 seconds.

Play must include:
- Large padel/court image carousel
- Search
- Filters
- Available Tonight courts
- Open Games Near You
- Top Courts This Week
- Clear actions: Book externally, Start ranked

## Imagery
Use only padel-specific or padel-adjacent imagery:
- padel courts
- glass padel courts
- padel rackets
- padel clubs
- indoor padel arenas
- outdoor padel venues
- premium sports club interiors

Do not use football, basketball, volleyball, kids sports, random team images, or clearly tennis-only imagery.

## Interaction rules
Every primary button must either navigate, open a modal/bottom sheet, or update local state. No dead primary actions.

Required working local-state interactions:
- search courts
- filter courts
- join open game
- accept/decline challenge
- submit match step flow
- confirm/dispute result
- ranking filters
- player detail navigation

## Navigation
Exactly 5 tabs:
1. Play
2. Rankings
3. Submit
4. Challenges
5. Profile

No extra Matches tab. No triangle icons. Use clean vector icons.

## Content rules
Use realistic Qatar/Gulf/expat player names and realistic Qatar court data. No names like Player 1 Al Doha. No raw dates like 2026-05-03 20:00. Use human times like Tonight, 8:30 PM.

## Quality bar
The app must feel like a premium investor-demo frontend, not a generic AI-generated prototype. If the UI looks flat, repeated, or fake, keep improving before claiming done.
