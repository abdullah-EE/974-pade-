# Design Skill Stack for 974 Padel

Use this skill stack for UI, UX, motion, layout, visual polish, product screens, and investor-demo work.

This file summarizes the external design skill principles requested for the project:
- Taste Skill
- UI UX Pro Max
- Impeccable
- Huashu Design
- Playwright-style visual QA

## Workflow
Before editing UI code:
1. Read AGENTS.md.
2. Read DESIGN.md.
3. Read this file.
4. Audit current screens against the rejection tests.
5. Fix the design system before randomly editing screens.

## Taste principles
- Layout must have hierarchy, not stacked generic cards.
- Typography must use clear size/weight contrast.
- Color must be restrained and intentional.
- Motion must support comprehension.
- The first screen must sell the app in under 10 seconds.

## UI UX Pro Max principles
- Use one consistent app style everywhere.
- Use fixed palette, spacing scale, button variants, card styles, typography rules, image rules, and motion rules.
- Mobile screens must be thumb-friendly.
- Primary actions must be obvious.
- Navigation must be simple.

## Impeccable principles
Avoid AI slop:
- generic rounded cards everywhere
- cramped padding
- low-contrast gray text
- random icons
- purple/blue gradients
- repeated filler cards
- dead buttons
- wrong imagery

Ask on every screen:
- What is the screen's job?
- What is the user's next action?
- What can be removed?
- What should be bigger?
- What should be quieter?
- What breaks credibility?

## Huashu Design principles
- Create strong visual direction before filling details.
- Build screens as a clickable product prototype.
- Use realistic content and image composition.
- Treat motion, cards, and flows as product storytelling.

## Visual QA principle
Before claiming done, inspect the result:
- Does the app run?
- Is there any red screen?
- Are there exactly 5 tabs?
- Is the first screen visually impressive?
- Do primary buttons work?
- Are all images relevant?
- Does the UI still look like a generic template?

## Final rejection test
Reject output if it has:
- wrong sport images
- generic placeholder users
- repeated images/content
- dead buttons
- extra tabs
- triangle icons
- blue/gold/black-dashboard leftovers
- crowded cards
- no working local interactions
- no image-led court discovery
